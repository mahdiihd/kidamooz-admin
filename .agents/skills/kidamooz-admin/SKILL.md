# توسعه پنل مدیریت کیدآموز

ابتدا [راهنمای پروژه](../../../AGENTS.md) و [مشخصات](../../../spec.md) را بخوانید.

1. قابلیت متناظر را در `src/app/features` پیدا کنید و سرویس و مدل مصرف‌شده توسط آن را دنبال کنید؛ الگوی یک صفحه هم‌نوع را مبنا قرار دهید.
2. برای تغییر API، مسیر و DTO متناظر را در پروژه همسایه `Back` بررسی کنید. رفتار واقعی و mock سرویس را هماهنگ نگه دارید.
3. مؤلفه جدید را مطابق بارگذاری تنبل در `src/app/app.routes.ts` اضافه کنید و آن را داخل محدوده محافظ مناسب قرار دهید.
4. در فرم‌ها، اعتبارسنجی ورودی، حالت ارسال، خطای پاسخ و بازخورد موفقیت را با الگوی فعلی سرویس اعلان هماهنگ کنید.
5. برای تغییر اجرایی `npm run build` را اجرا کنید؛ برای رفتار تغییرکرده از `npm test -- --watch=false` و بررسی رابط فارسی استفاده کنید. اسکریپت lint موجود نیست.

نسخه Angular این پروژه مستقل از اپ موبایل است. نشانی API را در مؤلفه‌ها ثابت نکنید و اعتبارنامه را در کد سمت مرورگر قرار ندهید.
